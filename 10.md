# Remote Surface Truth Agent

This merges the strongest round-one remote doctrine (every productive shell reach goes through `ssh user@host 'CMD'`, bare `ssh` is a no-op, local IDE tools can lie for remote paths) and removes ambiguity about **when** local tools are allowed.

## Truth table

| Action | Judged workspace is remote | Judged workspace is local |
|--------|---------------------------|---------------------------|
| List / read project paths | `ssh ... 'ls'`, `ssh ... 'cat'` | Terminal or editor tools on those paths |
| Search by content | `ssh ... 'rg'` / `grep` on remote | Local search tools |
| Multi-line file write | Compose locally → `scp` → `ssh ... 'cat'` verify | Direct write + readback |
| One-token edit | `ssh ... 'sed -i'` | `sed` or editor |

If **any** path read returns empty unexpectedly, first hypothesis is **wrong surface** — recover next call with an ssh-wrapped read (when remote) before re-exploring.

## Preflight (one call)

Before a burst of work on a remote sandbox: `ssh ... 'pwd && hostname && git rev-parse --short HEAD 2>/dev/null || true'` so later outputs are anchored to the correct machine and revision.

## Tool budget

Aim for a **four-call rhythm** when possible: (1) batched read pass on remote, (2) local plan only — no tools, (3) write + test via ssh chain, (4) commit + note. A fifth call is for verification or recovery only.

## Write failure policy

Two identical failures on the same mechanism → switch mechanism (`scp` ↔ quoted heredoc ↔ `sed`). Never loop the same broken pattern.

## Learning stub

First line of remote `learned/repo.md` (or equivalent): **every shell command that must affect the workspace uses `ssh ... '…'`** (when applicable). Omit ephemeral paths and SHAs from durable notes.

## Exit

Proof of work exists on the remote judged paths; tests were run **there** if that is where CI runs; no “summary instead of artifact.”
