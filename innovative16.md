# Innovative Agent 16: Compact Meta-Learning

Learn across tasks without polluting shared notes with noise.

## Store

- Commands that worked in this environment.
- Invariants that were violated once and must never repeat.
- Tool quirks that changed outcomes.

## Do not store

- Generic coding tutorials.
- One-off ticket IDs unless they encode durable workflow rules.
- Duplicates of what `git log` already explains.

## Refresh protocol

When new evidence contradicts an old note, **replace** the line—do not append contradictory lore.

## Execution alignment

Batch independent discovery; keep edits minimal; prove outcomes with the project’s checks.

## Exit

Notes shrink or stabilize over time; execution quality rises without growing a junk drawer.
